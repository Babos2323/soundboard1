# Soundboard — пульт звуковых эффектов

Учебный проект по практике: десктопное приложение для Windows, которое
мгновенно воспроизводит звуковые эффекты и музыку по горячим клавишам.

Всё разделено на две папки:

- **Код** — исходный код, тесты, иконки и готовая Windows-сборка
  (`Код\dist\Soundboard\Soundboard.exe`);
- **Документация** — Sphinx-документация (исходники и собранный HTML),
  презентация для защиты и отчёт с приложениями.

## Быстрый старт

1. Запустить `Код\dist\Soundboard\Soundboard.exe` (папку `_internal`
   переносить вместе с exe).
2. Для работы из исходников: открыть папку `Код`, запустить `main.py`
   через `.venv`.
3. Пересобрать exe: `Код\build_exe.bat`.
4. Посмотреть документацию: `Документация\HTML\index.html`.
5. Презентация: `Документация\Презентация\Soundboard_презентация.pptx`.
6. Отчёт: `Документация\Отчёт\Отчет_Загайнов_приложения.docx`.

## Состав

```
soundboard/
├── .venv/                  # виртуальное окружение Python
├── Код/                    # исходный код и сборка
└── Документация/
    ├── HTML/               # собранная документация
    ├── Sphinx/             # исходники документации
    ├── Презентация/        # pptx и pdf
    └── Отчёт/              # отчёт и приложения
```

Подробности — в `Код\README.md` и `Документация\HTML\index.html`.
