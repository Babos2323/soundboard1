API-справочник
==============

Раздел сгенерирован автоматически из docstrings исходного кода
(``sphinx.ext.autodoc`` + ``sphinx.ext.napoleon``). Описание классов
и публичных методов доступно ниже; исходный код можно открыть по ссылке
«[source]» рядом с каждым объектом.

.. note::

   Модули импортируются напрямую из папки приложения. При встраивании
   проекта в пакет достаточно изменить путь в ``conf.py``.
