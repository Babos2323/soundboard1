API-справочник

Раздел сгенерирован автоматически из docstrings исходного кода (sphinx.ext.autodoc + sphinx.ext.napoleon). Описание классов и публичных методов доступно ниже; исходный код можно открыть по ссылке «[source]» рядом с каждым объектом.

Примечание

Модули импортируются напрямую из папки приложения. При встраивании проекта в пакет достаточно изменить путь в conf.py.

Аудиодвижок

AudioEngine (Singleton): воспроизведение через pygame.mixer.

Сигналы (Observer) сообщают интерфейсу о начале, конце и текущей позиции звука. Маленький буфер (512 сэмплов ≈ 12 мс) обеспечивает задержку заметно меньше 100 мс.

Перемотка реализована без внешних зависимостей: у pygame.mixer.Sound нет позиции, поэтому нужный фрагмент вырезается из сырых PCM-данных (Sound.get_raw) и проигрывается как отдельный Sound с начала фрагмента.

class audio_engine.AudioEngine[исходный код]

Базовые классы: QObject

Движок воспроизведения на pygame.mixer (Singleton).

Управляет каналами, громкостью, перемоткой и зацикливанием, сообщает интерфейсу о событиях через сигналы Qt.

Интерфейс и диалоги

MainWindow (View + Controller): два экрана по макету Figma — главный и «Библиотека».

На главном экране карточка звука содержит встроенные регуляторы: перемотку (полоса прогресса), зацикливание и громкость конкретного звука. Список карточек прокручивается колесом мыши, а сетка всегда продолжается вниз, поэтому прокрутка работает и при небольшом количестве звуков.
